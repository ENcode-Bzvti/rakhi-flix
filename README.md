# 🧵 Rakhi Flix — Gift Site 

A Netflix-intro-style website with a funny "choose your didi" flow, ending
in a short closing message.

## 📁 What's in the folder

```
rakhi-gift/
├── index.html               <- all structure/content lives here
├── css/
│   └── style.css             <- all design/animation
├── js/
│   └── script.js              <- intro, navigation, confetti, music
├── assets/
│   ├── images/                 <- put profile photos here
│   │   └── readme.md             <- exact file names needed
│   └── audio/                   
│       └── readme.md                 <- optional: background music + intro sound
└── README.md
```

## ✅ Step 1 — Add your content 

1. Open `assets/images/readme.md` — it lists 4 exact file
   Drop matching photos into `assets/images/` with
   those exact names.
2. No photo yet? The site won't break — it shows a cute 📷 placeholder
   until you add one.
3. Want to tweak any of the story text? Open `index.html`, use Ctrl+F to
   find the line, and edit it directly — it's plain text, no coding
   needed.
4. (Optional) Audio — read `assets/audio/readme.md`:
   - `bg-music.mp3` — any Hindi track you already have, for the
     background-music toggle.
   - `intro-sound.mp3` — your own "ta-dum"-style sound for the intro, if
     you have one. Skip either file and that part just stays silent —
     nothing breaks.

## ✅ Step 2 — Test it locally

Just double-click `index.html` to open it in a browser.
(If audio/photos don't load that way, use a local server instead — some
browsers are strict about `file://` links.)

**With VS Code:**
1. Open the folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click `index.html` → "Open with Live Server".

**With Python (if installed):**
```
cd rakhi-gift
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

## ✅ Step 3 — Host it so you can send the link

Easiest free option — **Netlify Drop**:
1. Go to https://app.netlify.com/drop
2. Drag the whole `rakhi-gift` folder into the browser window.
3. You'll get a live link in seconds (e.g. `https://xyz123.netlify.app`).
4. Send that link on WhatsApp — it works on mobile, tablet, and PC, no
   app install needed.

**Alternative — GitHub Pages** (if you have a GitHub account):
1. Create a new repo and upload everything in this folder.
2. Repo Settings → Pages → select branch `main` → Save.
3. It'll be live at `https://<username>.github.io/<repo-name>/` within a
   few minutes.

## 🎬 Site flow

1. **Netflix-style intro** — glowing "R" logo animation, "RAKHI FLIX"
   tagline, skip button. No sound is generated by the code — if you add
   `intro-sound.mp3`, it plays that; otherwise it's silent.
2. **Selection screen** — two cards, "Person1 Didi" (6 years older, MA
   Psychology) and "Person2 Didi" (11 years older, Doctor/PG). Clicking
   either opens that person's page.
3. **Each didi's page** — a few funny story cards (text + emoji only, no
   photos, as requested) plus a hero photo at the top.
4. **Final screen** — confetti animation, a short closing line, and the
   "no money, make do with this" joke.

## 🛠️ Small customizations

- **Add your name:** in `index.html`, find `— tumhara bhai` near the
  bottom and add your name if you want.
- **Change colors:** at the top of `css/style.css`, the `:root{ ... }`
  block has `--saffron`, `--rose`, etc. — change the hex values and the
  whole site updates.
- **Change intro length:** in `js/script.js`, find
  `setTimeout(endIntro, 3600);` and change the number (milliseconds).

## 📱 Mobile / tablet / PC

The layout is already responsive — cards stack on small screens, text
scales down. Just keep photo files reasonably small (avoid 10MB+ images)
so it loads fast on mobile data — squoosh.app is a free, quick way to
compress them.
