You can place two audio files in this folder (both are optional):

1) bg-music.mp3
   Background music that can be played/paused using the 🔇 button
   (it plays continuously across the entire site). Just add any Hindi
   song or track you have—a 1–3 minute loop is sufficient,
   it will repeat automatically.

2) intro-sound.mp3
   If you have a sound similar to the Netflix "ta-dum",
   add it using this filename. It will play as soon
   as the intro starts. If the file is missing, the intro will simply
   play without sound—no problem at all.

Even if you don't add the files, the entire site will function normally;
nothing will simply play at that specific button/moment.
