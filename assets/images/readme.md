The story cards are currently without photos, only 4 profile photos are needed—place them in this folder (assets/images) using *exactly* these filenames. If you don't add them, the site won't break, a cute 📷 placeholder will appear instead.

Which photo    ->  File name (exact)
--------------------------------------------------
Person 1 circular photo (select screen)            -> person1.jpg
Person 1 large photo (her page header)             -> person1-hero.jpg
Person 2 circular photo (select screen)            -> person2.jpg
Person 2 large photo (her page header)             -> person2-hero.jpg

TIPS:
1. Either .jpg or .png format works—just make sure to use ".jpg" in the filename
   (if you are using .png, update the line for that photo in `index.html`
   by changing src="assets/images/xyz.jpg" to src="assets/images/xyz.png").
2. Avoid using very large photo files (10MB+), as they will load slowly on mobile.
3. A roughly square-shaped photo works best for the circular ones
